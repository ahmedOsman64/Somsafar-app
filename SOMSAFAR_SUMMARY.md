# SomSafar: Project Overview 🌍✈️🏨

SomSafar is a modern travel platform built to improve tourism and travel services in Somalia. It connects travelers with service providers using high-end technology.

## 🎯 Purpose
SomSafar was created to be the primary platform for discovering and booking tourist destinations, hotels, and adventures in Somalia.

## ✨ Key Components

### 1. Traveler App
- **Easy Search:** Find hotels and resorts using advanced filters.
- **Real-time Chat:** Direct messaging between travelers and service providers.
- **Secure Booking:** A simple 5-step process to complete your booking.

### 2. Provider Portal
- **Service Management:** Add or edit rental properties and travel services.
- **Revenue Insights:** A dashboard showing earnings and business performance.
- **Booking Management:** View and manage guest reservations.

### 3. Admin Dashboard
- **Platform Monitoring:** Overview of user numbers, services, and total revenue.
- **Data Security:** Protecting user privacy using Row-Level Security (RLS).

## 🛠️ Technology Stack
- **Mobile First:** Built with **Flutter** using Material 3 design.
- **Modern Backend:** Powered by **Supabase** for real-time data.
- **Security:** PostgreSQL Row-Level Security keeps data safe and private.

## 🚀 Development Progress
1.  **Migration:** Moved from Firebase to Supabase for better performance and scale.
2.  **Localization:** Fully translated to Somali for local users.
3.  **Rebranding:** Updated categories like "Tourism" and improved region discovery.
